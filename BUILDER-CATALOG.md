# Builder catalog

The internal level workshop exposes all 100 approved asset ideas. Each entry
has a primary gameplay verb, an environment profile, and a reviewed raster
family for its thumbnail and placement preview. Shared families keep pivots,
joins, and collision previews deterministic while the art library expands.

Timed ideas are authored as jump, roll, or cover decisions for the static
scroller. The playground intentionally spaces every idea on a long horizontal
shelf so each one can be inspected without art clipping or overlap.

The source of truth is [`game/builder-catalog.js`](game/builder-catalog.js).
Use **Asset playground** in the editor to place all 100 entries, search by
purpose, inspect the footprint, and move an item into a test composition.
