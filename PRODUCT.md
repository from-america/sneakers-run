# Product

## Register

product

## Users

Players use Sneakers Run for a short, replayable arcade escape on phone,
keyboard, or Steam controller. Internal designers use the level editor to
author and inspect routes with the same artwork, dimensions, and collision
rules as the shipping game.

## Product Purpose

Sneakers Run turns the Famous Moji artwork into a responsive city runner with
authored multilevel routes, readable hazards, forgiving controls, and useful
replay goals. Success means every encounter reads before it reaches the player,
every visible surface behaves as drawn, and a complete run feels fair at speed.

## Brand Personality

Expressive, streetwise, and precise. The interface should feel like a small
independent arcade release whose artwork carries the personality while its
controls remain direct and trustworthy.

## Anti-references

Avoid generic game-dashboard cards, neon sci-fi chrome, decorative motion,
remote UI kits, and editor controls that hide world coordinates or collision
meaning. Do not introduce vector substitutes for approved raster game art.

## Design Principles

- Make the next action readable at running speed.
- Let the approved artwork lead without weakening control clarity.
- Keep simulation, editor dimensions, and collision truth in one shared model.
- Prefer direct manipulation with immediate, reversible feedback.
- Treat keyboard, controller, touch, reduced motion, and color-independent cues as core behavior.

## Accessibility & Inclusion

Controls remain keyboard reachable with visible focus, semantic labels, and
text alongside color. Gameplay offers reduced motion, background contrast, and
a relaxed pace. Internal tools support keyboard deletion, duplication,
undo/redo, and numeric editing in addition to pointer dragging.
